# Бот челенджу 90 днів — встановлення (≈30 хв, у суботу)

## 1. Новий бот
@BotFather → `/newbot` → скопіюй токен.

## 2. Таблиця і код
1. **sheets.new** → назви «90 днів».
2. **Розширення → Apps Script**.
3. ⚙ **Налаштування проєкту** → Часовий пояс: **(GMT+02:00) Madrid**.
4. У `Код.gs` встав вміст `Code.gs`.
5. **«+» → HTML → `Dev`** → встав вміст `Dev.html`.
6. Заповни: `BOT_TOKEN`, `GEMINI_API_KEY` (той самий ключ), `DASH_KEY` (новий пароль). `OWNER_ID` поки лиши 0. Збережи.

## 3. Запуск
1. Функція **setup** → Запустити → дозволити доступ.
2. **Ввести в дію → Нове введення в дію → Вебдодаток**: виконувати як «Я», доступ «Усі». Скопіюй URL.
3. Встав URL у `WEBAPP_URL`, збережи → функція **setWebhook** → Запустити.
4. Напиши новому боту `/start` → він покаже твій ID → впиши в `OWNER_ID` → збережи.
5. **Нова версія** розгортання (Керувати введеннями в дію → ✏️ → Нова версія).
6. Функція **installTriggers** → Запустити. Це вмикає ранок 7:30, контроль о 15:00, вечір о 21:00, пізнє нагадування о 23:30 і недільний огляд о 19:00.

### Оновлення з попередньої версії
1. Заміни `Код.gs` і `Dev` новими файлами (твої токени й ключі перенеси зі старого коду!).
2. Запусти **setup** — з'являться вкладки «Щоденник» та «Ідеї».
3. Запусти **setWebhook** (нові команди в меню) і **installTriggers** (нове пізнє нагадування).
4. **Нова версія** розгортання.

## 4. Тест
1. Функція **testWords** → у журналі 5 слів, а у вкладці «Слова» нові рядки.
2. Надиктуй боту: «вчора написав 20 дизайнерам, займався іспанською 20 хвилин і англійською 15».
3. Заміри дня 1: `#вага 80.5` · `#підтягування N` (твій максимум).
4. `/words` — слова на сьогодні, `/dash` — дашборд.

## Корисно
- Після **будь-якої** зміни коду → Нова версія розгортання.
- Годинники змінюються в `MORNING_HOUR`, `NUDGE_HOUR`, `EVENING_HOUR`, `REVIEW_HOUR` → потім ще раз **installTriggers**.
- Цілі на 90 днів — у `GOALS_90`, тижневі — у `DEV_TARGETS` (англійська: `'Англійська': 105` хв на тиждень).
- Бал «Мови» = середнє з трьох: хвилини іспанської, слова, хвилини англійської.
- Бот мовчить → функція **checkWebhook**, дивись `last_error_message`.

## Звички і контроль
- 8 щоденних звичок (`HABITS`): план, продажі, іспанська, англійська, читання, музика, без сигарет, підсумок. Більшість відмічаються самі із записів; кнопки — у /habits і у вечірній перевірці.
- Правило «ніколи не пропускай двічі»: зранку бот показує, що пропущено вчора, а два пропуски поспіль — жорстко.
- Тон — у `TAUNTS` і `DOUBLE_MISS`, можна дописувати свої фрази.
- Ідеї, які відволікають від продажів, бот складає у вкладку «Ідеї» і показує в неділю.
- `/es текст`, `/en текст` — переклад повідомлень для клієнтів у WhatsApp (або переклад повідомлення клієнта + варіант відповіді).
- Працюєш вночі? Зсунь `MORNING_HOUR`, `NUDGE_HOUR`, `EVENING_HOUR`, `LATE_HOUR` і запусти **installTriggers**.
