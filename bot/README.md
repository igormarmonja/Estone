# Бот челенджу 90 днів — встановлення (≈30 хв, у суботу)

## 1. Новий бот
@BotFather → `/newbot` → скопіюй токен.

## 2. Таблиця і код
1. **sheets.new** → назви «90 днів».
2. **Розширення → Apps Script**.
3. ⚙ **Налаштування проєкту** → Часовий пояс: **(GMT+02:00) Madrid**.
4. У `Код.gs` встав вміст `Code.gs`.
5. **«+» → HTML → `Dev`** → встав вміст `Dev.html`.
6. Заповни: `BOT_TOKEN`, `GEMINI_API_KEY` (той самий ключ), `DASH_KEY` (новий пароль). `OWNER_ID` поки лиши 0. Збережи.

## 3. Запуск
1. Функція **setup** → Запустити → дозволити доступ.
2. **Ввести в дію → Нове введення в дію → Вебдодаток**: виконувати як «Я», доступ «Усі». Скопіюй URL.
3. Встав URL у `WEBAPP_URL`, збережи → функція **setWebhook** → Запустити.
4. Напиши новому боту `/start` → він покаже твій ID → впиши в `OWNER_ID` → збережи.
5. **Нова версія** розгортання (Керувати введеннями в дію → ✏️ → Нова версія).
6. Функція **installTriggers** → Запустити. Це вмикає ранок 7:30, нагадування о 15:00, вечір о 21:00 і недільний огляд о 19:00.

## 4. Тест
1. Функція **testWords** → у журналі 5 слів, а у вкладці «Слова» нові рядки.
2. Надиктуй боту: «вчора написав 20 дизайнерам і займався іспанською 20 хвилин».
3. Заміри дня 1: `#вага 80.5` · `#підтягування N` (твій максимум).
4. `/words` — слова на сьогодні, `/dash` — дашборд.

## Корисно
- Після **будь-якої** зміни коду → Нова версія розгортання.
- Годинники змінюються в `MORNING_HOUR`, `NUDGE_HOUR`, `EVENING_HOUR`, `REVIEW_HOUR` → потім ще раз **installTriggers**.
- Цілі на 90 днів — у `GOALS_90`, тижневі — у `DEV_TARGETS`.
- Бот мовчить → функція **checkWebhook**, дивись `last_error_message`.
