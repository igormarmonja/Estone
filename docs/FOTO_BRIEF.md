# Фото для лендингу — що потрібно і як додати

## Як це працює

Кладете файл із потрібним іменем у папку `assets/img/` — заглушка зникає сама, фото стає на місце.
Нічого в коді міняти не треба. Ім'я файлу має збігатися точно, разом з розширенням `.jpg`.

Поки файлу немає — на його місці стоїть акуратна заглушка, яка показує, що саме туди має потрапити.
Сайт при цьому виглядає цілісно, його можна показувати й лити трафік.

---

## Технічні вимоги

| Параметр | Значення |
|---|---|
| Формат | JPG |
| Ширина | 1600 px по довгій стороні (більше не треба, менше — втрачається різкість) |
| Пропорції | горизонтальні, приблизно 4:3 або 3:2 |
| Вага | до 400 КБ (стисніть через squoosh.app або tinypng.com) |
| Орієнтація | горизонтальна для всіх, крім каталогу умивальників |

**Головне правило:** краще п'ять справжніх фото своїх об'єктів, ніж п'ятдесят каталожних кадрів
виробників плити. Чужі каталожні фото Google бачить на десятках сайтів — вони не дають ані довіри,
ані унікальності. Знімок на телефон при денному світлі працює краще за чужий рендер.

## Що ще варто відзняти на майбутнє

Не для лендингу, а для основного сайту й розділу «Об'єкти»:

- **Виробництво:** ЧПУ-верстат у роботі, шліфування, контроль плити. Це те, чого немає в перекупів,
  і найсильніший доказ, що виробництво справді своє.
- **Процес монтажу:** бригада на об'єкті, замір, стикування полотен.
- **Зразки декорів:** розкладка зразків каменю — знадобиться для каталогу кольорів.
- **Фото «до / після»** на об'єктах реконструкції.
